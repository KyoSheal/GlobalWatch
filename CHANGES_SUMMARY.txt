3. NEW UTILITY FUNCTIONS
================================================================================

A. log_error(message)
   - Creates outputs/ directory if not exists
   - Writes to outputs/error.log with timestamp
   - Protected with try/except to prevent logging crashes
   - Format: [YYYY-MM-DD HH:MM:SS] message

B. safe_format_number(value, decimals=2, default="N/A")
   - Handles None/NaN/inf gracefully
   - Returns formatted string or default
   - Prevents number formatting crashes
